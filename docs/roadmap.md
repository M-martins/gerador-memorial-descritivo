# Roadmap

## MVP 1.0
- CSV, GeoJSON e desenho no mapa.
- Reprojeção básica para SIRGAS 2000 / UTM 23S.
- Cadastro de confrontações e dados do imóvel.
- Prévia obrigatória.
- PDF com croqui e quadros técnicos.
- Protocolo, chave de validação e SQLite.

## Versão 1.1
- Upload de Shapefile ZIP.
- Upload de DXF com seleção de polígonos fechados.
- DOCX editável.
- Melhorias no croqui: escala gráfica, norte, rótulo das faces.

## Versão 2.0
- Integração ArcGIS Enterprise.
- Hosted Feature Layer para geometria.
- Hosted Table para emissões.
- Anexos PDF/DOCX.
- Recuperação por protocolo diretamente no portal.
